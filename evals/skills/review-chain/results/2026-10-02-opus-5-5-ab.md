## ⚠️ Harness caveat — read before trusting any number

Same **condensed harness** shape as `2026-07-29-prompt-refactor-ab.md`, not the full
`/correctness-review` + `/intent-review` pipeline: one blind reviewer per fixture doing a combined
correctness + intent pass and self-reporting confidence 0–100 per finding (a proxy for the SCORE
stage). Blindness is by construction: `claude -p … --tools ""`, run from an empty directory, with
only `intent.md` and `diff.patch` inlined. The prompt is in the runner file; it is not the
2026-07-29 prompt (that one was not recorded), so **do not trend against earlier result files** —
the valid comparison is old vs new from this sitting.

Grading was done by a separate agent against each `truth.md`, with the arms anonymized as A/B
(A = new, B = old; key held by the controller).

- **Correctness/intent fixtures: old 4/5, new 4/5** — same catches; both effectively miss
  `soft-delete-filter` (old's 15-confidence conditional catch would never reach the fix loop).
- **All 7 fixtures:** old 4/7 clean catches, new 6/7 (both context-propagation catches are bonus;
  those fixtures expect correctness/intent to miss).
- **False positives:** old **20** (2 at ≥ 75: `excess-scope` new-endpoint "excess" at 80,
  `none-deref` `require_admin` "excess" at 85 — both pre-declared FPs in `truth.md`); new **13**
  (0 at ≥ 75).
- **Cost:** median elapsed per fixture old ≈ 60 s vs new ≈ 27 s; output tokens per fixture old
  ≈ 2.1k–4.5k vs new ≈ 1.0k–2.1k (≈ 2.2× less).

## Qualitative differences

- **Calibration.** Old scored unverifiable findings about code outside the diff at 65–70; new
  scored the same class at 20–35 and said why.
- **`require_admin` on `none-deref`.** Both misread the deliberate authz; only old's (85) would
  cross the fix-loop threshold.
- **Shared ≥ 75 issue.** Both arms flagged the `intent-gap` owner scoping as unrequested excess at
  92 — `truth.md` treats it as a deliberate fixture repair. Not an arm difference.
- **Noise.** New appended an unrelated connector-authorization note to 4 of 7 reviews (session
  chatter from the user-level profile); it did not affect scoring.

## Limitations

- **n = 1 per cell**, one client version; no variance estimate.
- Condensed harness and self-reported confidence; not the 6-angle FIND → independent SCORE pipeline.
- Both arms share the user-level `~/.claude` profile.
- `soft-delete-filter` still depends on the removed stack profile (see `2026-07-29-prompt-refactor-ab.md`
  Follow-up); its row is uninformative.
- Measures only these seven planted classes; unseeded classes are unmeasured.
