# Portable depth classifier

Use this reference with `rules/research-depth.md`. Deep signals are migration/schema/data loss,
high-blast files, new external integrations or dependencies, shared runtime configuration, and
auth/session/transaction scope. Quick requires all of: no Deep signal, no more than one file, no
new public callable in shared code, no dependency or public API change, and no entry-point work.

Examples: a typo or internal display method can be Quick; an endpoint or shared helper is Standard;
a migration, provider integration, dependency addition, or shared configuration edit is Deep.
