# Specs

`specs/` is local scratch space. Keep it gitignored: nothing here is committed or shared.

Use `specs/<slug>/` for working notes while a change is in progress, for example a draft
`design.md`, a `research-brief.md` or a `PLAN.md`. Delete it when the change ships.

Anything worth keeping goes to a tracked place instead:

- designs and decisions: `docs/adr/`
- reusable learnings: `docs/solutions/`

See [../skills/README.md](../skills/README.md) for the workflow map.
